# Report templates

Paste these into OpenSEO under a project → **Reports → Templates → New**.
Name and description go in their own fields; the rest of the file is the
Instructions body.

A template is per project, so the same text gets added once per client. The
agent still writes the document; the template replaces the section list and
tone it would otherwise default to.

| File | Name to use | When |
| --- | --- | --- |
| `ai-visibility-report.md` | AI Visibility Report | Monthly or quarterly client update on AI answer visibility |
